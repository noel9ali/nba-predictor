# C6 · Rank bump chart: no overlaps; phones keep ranks, right names and values

## 1. Problem
Model Chapter 5 bump chart: the "0.209" value label overlaps the "lower is better" column subtitle; at 768 values touch
names; on phones the chart drops rank numbers, right-side names and values, and the headers are cramped.
Screenshots: `design/hardwood/audit/shots/C4-bump-1440.png`, `design/hardwood/audit/shots/C4-bump-400.png`.

## 2. Repro
`/model?sample=1` at 400, 768, 1440 (also 320 and 560 — the narrow switch is at W < 560): `scrollTo(p, '#ch5 [data-bump]', 2200)`
(the line draw-in takes ~1.6s + 1.2s for values).

## 3. Root cause
`public/static/js/model/tryouts.js` `drawBump()` lines ~165–198:
- `T = 58` (wide); column heads at y=18, subtitles ("higher/lower is better") at y=34; the production line's value
  labels at `ry(rk) − 13` → for rank 1 that's y=45, overlapping the subtitle band (y ≈ 25–36) at font 11px … and the
  head row.
- `L = R = 170` fixed (wide); names are drawn at `cx(0) − 14` (end) and `cx(C−1) + 14` (start) without measuring.
- narrow (`W < 560`): `L=96, R=24`, no `.rk` rank numbers, no right names, no `.vl` values, left names abbreviated.
CSS `public/static/css/model.css` ~114–126 (`.bump .col/.colsub/.rk/.nm/.vl`).

## 4. Files owned
- `public/static/js/model/tryouts.js` (only `drawBump` and helpers)
- `public/static/css/model.css` (only `.bump …` rules)

## 5. Complete solution looks like
Prototype: `handoff/reference/prototypes/model.html`, "Six models tried out".
- **Header band**: the subtitle ("higher is better"/"lower is better") goes ABOVE the column head:
  subtitle y = 14, head y = 32 (wide). Plot top `T = 66` (wide) so the rank-1 value label (`ry(1) − 13` = 53, top ≈ 44)
  clears the head (bottom ≈ 34) by ≥ 8px. Narrow: no subtitle; head (short names) at y = 16; `T = 44`.
- **Measured gutters** (wide): measure the widest full name and the widest value with a hidden probe `<text>` in the SVG
  (`getComputedTextLength()`), then `R = maxNameWidth + 14 + 8` and `L = 28 (rank numbers) + maxNameWidth + 14 + 8`.
  Clamp so the plot (W − L − R) is at least 3 × 70px; if it can't be, switch to the narrow layout.
- **Narrow layout** (W < 560 or plot too small): keep rank numbers `.rk` on the far left (x = 4), DROP the left-side
  names, keep right-side names (abbreviated with `abbreviate()`), and keep the production line's value labels.
  `L = 28`, `R = measured abbreviated name width + 22`. The production name stays bold/orange.
- **Values vs names**: value labels are centred on their node; if a value label's box would intersect a name label
  or another value label, place it below the node (`ry(rk) + 24`) instead; if still blocked, hide it (its value is in
  the table below).
- All text ≥ 11px rendered (the SVG is drawn 1:1 at the host width — keep `width`/`height` attributes = W/H).
  `.bump .colsub` is 10px today → make it 11px.
- Line draw-in animation and reduced motion unchanged. Table and "why" card unchanged.
