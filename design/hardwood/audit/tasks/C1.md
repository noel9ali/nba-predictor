# C1 · Tonight calibration card: no label collisions, y-axis title, real-size text

## 1. Problem
In Tonight's "Is it calibrated?" card: the "40%" y label and the "50%" x label collide at the origin; the caption
"Model said · dot size = picks" touches the x tick labels; there is no y-axis title and no "perfect" label; at 768
the SVG scales up (huge, with text out of proportion).
Screenshots: `design/hardwood/audit/shots/C1-tonight-calibration-1440.png`, `design/hardwood/audit/shots/C1-tonight-calibration-768.png`.

## 2. Repro
`/?sample=1&scene=live` at 400, 768, 1440: `scrollTo(p, '[data-testid=calib]', 1500)`.

## 3. Root cause
`public/static/js/calibration-chart.js` `renderCalibration(host, buckets, { variant: 'card' })` lines ~15–55:
- card `pad = { l: 44, r: 12, t: 12, b: 34 }`; y labels at `(pad.l − 6, cy(v) + 4)`; x labels at `y = H − 16`;
  caption at `y = H − 2` → x ticks and caption 14px apart (touching), "40%" (at the plot's bottom-left) and "50%"
  (just below it) overlap.
- no y title; the "perfect" label is drawn only for the chapter variant (`if (!card)`).
- `W = max(260, host.clientWidth)`, the SVG gets `width`/`height` attributes but CSS
  (`public/static/css/components.css` `.calib-svg{width:100%;height:auto}`) stretches it to the card at 768 (the
  `.mgrid` stacks to one column ≤900px, so the card is ~700px wide while W was measured earlier/smaller).

## 4. Files owned
- `public/static/js/calibration-chart.js` (only the `card` variant paths; do not change the chapter variant's output)
- `public/static/css/tonight.css` (only a new rule for `[data-testid=calib] svg` sizing)

## 5. Complete solution looks like
Card variant only (prototype: `handoff/reference/prototypes/tonight.html`, "Is it calibrated?" card):
- Size: `W = min(420, max(260, host.clientWidth))`, `H = round(W × 0.72)` as now. CSS in tonight.css:
  `[data-testid=calib] .calib-svg{max-width:420px;margin-inline:auto}` so the SVG renders at 1:1 (rendered width ==
  W) and is centred in the card at 768 (and at 400 if the card is wider than W). Text renders at its CSS size (11px).
- Padding: `pad = { l: 58, r: 14, t: 14, b: 54 }`.
- y tick labels (40/60/80/100%) right-anchored at `x = pad.l − 8`, `y = cy(v) + 4` (unchanged pattern).
- x tick labels (50/60/70/80%) at `y = H − pad.b + 18` (18px below the plot's bottom edge), middle-anchored.
  The "40%" y label (baseline at the bottom edge + 4) and "50%" x label (baseline 18px below the edge) no longer overlap.
- Caption "Model said · dot size = picks" at `y = H − 6`: ≥ 12px clear gap between the bottom of the x tick labels and
  the top of the caption.
- y-axis title `Actually won`: `<text class="ax" text-anchor="middle" transform="rotate(-90)" x="-(plot mid y)" y="14">`
  — vertical, left of the y tick labels, centred on the plot height, not touching the tick labels (≥ 4px gap).
- "perfect" label: `<text class="ax">perfect</text>` placed along the dashed diagonal near its top-right end,
  rotated to the diagonal's on-screen angle (`atan2(dy, dx)` in degrees; negative because SVG y grows down), sitting
  4–8px above the line, text-anchor `end`, ending ~10px before the diagonal's end point. If its box would intersect a
  dot (circle bbox) or another label, slide it down the diagonal (towards the origin) in 10px steps until clear.
- Everything inside the SVG viewBox; no text under 11px rendered size.
- The T17 dot pop-in animation and `--k` stagger unchanged; reduced motion unchanged.

## 6. Out of scope

## 7. Acceptance tests (`tests/e2e/audit/C1.mjs`)

- Collect every `<text>` in `[data-testid=calib] svg`: no two bounding rects intersect (`intersects(a, b, 0)` false);
  each text's rendered font size ≥ 11px (`parseFloat(getComputedStyle(t).fontSize) * (svgRect.width / viewBox.width) >= 10.95`).
- Rendered SVG width equals its viewBox width ±1px and is ≤ 420px; at 768 `|leftGap − rightGap| ≤ 2` between the SVG
  and the card's content box.
- A text 'Actually won' exists with a rotate transform; a text 'perfect' exists.
- Caption top − max(x tick label bottoms) ≥ 12px.
- Every text rect is inside the card rect.
- `page.errors` empty.
