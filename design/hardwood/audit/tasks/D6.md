# D6 · Pass stub: "PICK" / "NO BET" on two even lines by design

## 1. Problem
On tickets without a bet, the desktop stub's label "PICK · NO BET" doesn't fit the 72px stub column and wraps
unevenly ("PICK · NO" / "BET" or similar). Screenshot: `design/hardwood/audit/shots/D6-pass-stub-wrap.png`.

## 2. Repro
`/?sample=1&scene=nobets` (all passes) and `scene=live` (some passes) at 400, 768, 1440. Look at `.stub .who` on
tickets whose stub says "Pick · no bet".

## 3. Root cause
- `public/static/js/tonight/tickets.js` `stubHTML()` ~85–98: `who = b ? 'Bet on' : 'Pick · no bet'` as one text run
  before `<b class="stub-pick">`.
- `public/static/css/components.css` ~179–182: stub 96px wide, 12px side padding, 11px mono uppercase with .06em
  letter-spacing → ~95px needed for "PICK · NO BET".
At ≤ 560px the stub is a horizontal strip and the label fits on one line — keep that.

## 4. Files owned
- `public/static/js/tonight/tickets.js` (only the `who` part of `stubHTML`)
- `public/static/css/components.css` (only `.stub .who …` rules)

## 5. Complete solution looks like
- Markup for the pass label: `Pick<span class="who-sep"> · </span><span class="who-2">no bet</span>` (static text, no
  API data). "Bet on" and "Pick pending" are unchanged.
- Desktop (> 560px): `.stub .who .who-sep{display:none}` and `.stub .who .who-2{display:block}` → two lines "PICK" /
  "NO BET", same font, the same line-height as the stub's other labels, so the gap between "PICK" and "NO BET" equals
  the label line-height (no extra margin), and the pick tricode follows with its usual 5px margin.
- ≤ 560px: separator visible, `who-2` inline → "PICK · NO BET" on one line as today.
- Screen readers read "Pick · no bet" / "Pick no bet" — fine either way.

## 6. Out of scope
Stub layout (D5), notches (B5), aria-labels (B3).

## 7. Acceptance tests (`tests/e2e/audit/D6.mjs`)
For w in 400, 768, 1440, scene nobets, every `.stub .who` of a pass ticket:
- > 560: the label text (excluding `.stub-pick`) occupies exactly 2 line boxes: "PICK" on line 1, "NO BET" on line 2
  (Range client rects grouped by top); `.who-2` rect width ≤ stub content width.
- ≤ 560: the label is 1 line.
- Bet stubs ("Bet on") unchanged: 1 line.
- `page.errors` empty.
