# C5 · One money format in the season section's titles and copy

## 1. Problem
The bankroll step title "From $1,000.00 to $1,111.67" was flagged as a cents inconsistency against other copy. The
ruling: use the format the scorers board uses. Every board in the app prints money with cents via `fmt.money`
(`$1,111.67`, `+$111.67`, `$1,000.00`), so titles and step copy must also use `fmt.money` (always cents). Axis tick
labels (`$1,050`) are a chart scale, not money values, and stay without cents.

## 2. Repro
`/?sample=1&scene=live`, `scene=nobets`, `scene=final`, past `/?sample=1&date=2026-11-16` at 1440. Read
`#season` text: `[data-season-kick]`, `[data-testid=season-board]`, `.bstep h4`, `.bstep p`, `[data-bstep-t]`, the chart's
`aria-label`, the tooltip text (focus the chart, ArrowLeft), `[data-wl-card]`, `[data-testid=mfacts]`.

## 3. Root cause / current state
`public/static/js/tonight/season.js` `stepText()` (~39–64) and `renderSeasonBoard()` already use `fmt.money` for money.
Find any money string in the season section that is NOT produced by `fmt.money` (hard-coded "$1,000", `toFixed`,
`toLocaleString` with `$`) — e.g. step copy written by hand. Expected: possibly none.

## 4. Files owned
- `public/static/js/tonight/season.js` (only string building in `stepText`, `renderSeasonBoard`, tooltip text)

## 5. Complete solution looks like
- Every dollar amount in the season section's text (titles, step paragraphs, board, kicker, tooltip, aria-labels) matches
  `/[+−±]?\$\d{1,3}(,\d{3})*\.\d{2}/` (cents always), except y-axis tick labels (`text.ax`) which match `/^\$\d{1,3}(,\d{3})*$/`.
- If something doesn't match, change it to use `fmt.money`. If everything already matches, make no code change and
  report "no change needed" with the evidence.

## 6. Out of scope
Chart geometry (C3/C4), tooltip placement (B2), dashes in "bets 2-1" (D4).

## 7. Acceptance tests (`tests/e2e/audit/C5.mjs`)

find every `$` amount with `/[+−±-]?\$[\d,]+(\.\d+)?/g`; every match outside `text.ax` must have exactly two decimals
and use `−` (U+2212), not '-', for negatives. Step 1 title matches `/^From \$[\d,]+\.\d{2} to \$[\d,]+\.\d{2}$/`.
`page.errors` empty.
