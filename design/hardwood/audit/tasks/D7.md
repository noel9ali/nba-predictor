# D7 · Team names ellipsize, records stay visible

## 1. Problem
On tickets the team line "Minnesota Timberwolves · 6–5" is ellipsized as a whole, so the record disappears
("Minnesota Timberwolves · …"; on phones "Miami Heat…"). Screenshot: `design/hardwood/audit/shots/D7-D11-names-glyph-1440.png`.

## 2. Repro
`/?sample=1&scene=live` and `scene=final` at 320, 400, 768, 1440. Every `.ticket .tname`.

## 3. Root cause
- `public/static/js/tonight/tickets.js` `teamRow()` ~72–83: `name = [t.name, wl(t.record)].join(' · ')` in one
  `<span class="tname">`.
- `public/static/css/components.css` ~203: `.tname{white-space:nowrap;overflow:hidden;text-overflow:ellipsis}`.

## 4. Files owned
- `public/static/js/tonight/tickets.js` (only the `tname` markup in `teamRow`)
- `public/static/css/components.css` (only `.tname` rules)

## 5. Complete solution looks like
- Markup: `<span class="tname"><span class="tn-n">Minnesota Timberwolves</span><span class="tn-r"> · 6–5</span></span>`
  (both parts escaped with `esc`; record via `wl()`; if there's no record, omit `.tn-r`; if no name, omit `.tn-n`).
- CSS: `.tname{display:flex; min-width:0; …existing font/colour}`; `.tn-n{min-width:0; overflow:hidden;
  text-overflow:ellipsis; white-space:nowrap}`; `.tn-r{flex:none; white-space:pre}` (keep the leading space).
  Only the name gets an ellipsis; the record is always fully visible.
- Layout of the team row (logo, tricode, BET ON tag, name, score) otherwise unchanged.

## 6. Out of scope
Dashes (D4 — the record already goes through `wl`), stub, drawer.

## 7. Acceptance tests (`tests/e2e/audit/D7.mjs`)
For each width × scene, every `.tname`:
- `.tn-r` (when present) is fully visible: its rect is inside the `.tname` rect and inside the `.ticket` rect,
  and `tn-r.scrollWidth <= tn-r.clientWidth + 1`.
- `.tn-r` text matches /^ · \d+–\d+$/.
- `.tname` rect right ≤ the score element's rect left (no overlap with the score).
- `page.errors` empty; no horizontal overflow at 320.
