# D1 · Phone header ≤ 120px: one scrollable tab row, status + sample tag on the brand row

## 1. Problem
At phone widths the nav tabs wrap ("The model" alone on a line) and the status pill + sample tag take another row, so
the header is ~235px tall at 400px (measured). Screenshot: `design/hardwood/audit/shots/D1-D2-phone-nav-kicker.png`.

## 2. Repro
`/?sample=1&scene=live` and `/model?sample=1` at 320, 360, 400, 480, 768, 1440. Measure `header.top` height.

## 3. Root cause
`public/static/css/components.css` ~5–21 and ~265–267: `.top{display:flex;flex-wrap:wrap;gap:20px 28px;padding-block:22px}`;
`.tabs{display:flex;gap:4px;flex-wrap:wrap}`, tabs `min-height:48px; padding:0 14px`; `.top__r{margin-left:auto;…;flex-wrap:wrap}`;
`@media (max-width:700px){.top__r{min-height:24px}}`. Markup (both pages): `header.top > .brand, nav.tabs, .top__r`.

## 4. Files owned
- `public/static/css/components.css` (only `.top`, `.brand`, `.tabs`, `.top__r`, `.status`, `.sample-tag` rules)

## 5. Complete solution looks like
At `max-width: 480px` only (above that, unchanged):
- `.top` becomes a 2-row grid: row 1 = brand (left) + `.top__r` (right, status pill and sample tag on ONE line, no
  wrap, `justify-self:end`, may shrink the status text with ellipsis); row 2 = the tabs spanning the full width.
  `padding-block: 10px`, row gap 6px.
- `.tabs`: `flex-wrap:nowrap; overflow-x:auto; scroll-snap-type:x proximity; scrollbar-width:none` (and
  `::-webkit-scrollbar{display:none}`), each tab `scroll-snap-align:start; flex:none; padding:0 12px`, still
  `min-height:44px` (touch target ≥ 44px). Tab labels unchanged ("Tonight", "Past nights", "Season", "The model").
  The tab row scrolls inside itself; the PAGE never scrolls horizontally.
- The current tab (`aria-current`) shows its underline as now. If the current tab is off-screen in the scroller at load
  (e.g. "The model" on the Model page at 320px), it's acceptable for this task to leave it — but report whether it is.
- Header height ≤ 120px at 320–480px on both pages (sample tag + status visible).
- Focus ring on tabs fully visible (not clipped by the scroller): give the scroller `padding-block:4px` if needed.

## 6. Out of scope
The page kicker (D2), the ribbon, markup changes (CSS only).

## 7. Acceptance tests (`tests/e2e/audit/D1.mjs`)
For w in 320, 360, 400, 480 on both pages:
- `header.top` height ≤ 120.
- All 4 tabs have the same `top` (one row); each tab height ≥ 44.
- `.top__r` children (visible ones) share one row (same top ±2) and lie inside the header.
- `document.documentElement.scrollWidth <= innerWidth` (no page overflow).
- Keyboard: Tab from the top of the page reaches all 4 tabs in order.
For w in 768 and 1440: header height equals the before-value (record it in the test from the current CSS: 182 at 768,
95 at 1440 on Tonight; ±2px).
`page.errors` empty.
