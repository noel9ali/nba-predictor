# D3 · No line breaks inside records, scores or money

## 1. Problem
The final lede breaks the bet record across lines ("Bets went 4–" / "1 for"); the drawer meta line breaks mid-number on
phones ("112–" / "104"). Screenshots: `design/hardwood/audit/shots/D3-D10-final-lede-wrap.png`,
`design/hardwood/audit/shots/D3-drawer-meta-wrap-400.png`.

## 2. Repro
- Lede: `/?sample=1&scene=final`, `scene=live`, `scene=nextup`, `scene=nobets`, past `/?sample=1&date=2026-11-16` at
  320, 400, 768, 1440 → `[data-testid=hero]`.
- Drawer: `/?sample=1&scene=final` at 320/400/768/1440, click each of the first 4 `.ticket__hit`s → `.drawer [data-meta]`.

## 3. Root cause
- `public/static/js/tonight/glance.js` `sentence()`: numbers are wrapped in `<span class="n">` (via `n()`), but
  `.lede h1 .n` (`public/static/css/tonight.css` ~line 4) allows wrapping at the en dash / minus.
- `public/static/js/tonight/drawer.js` `metaText(g)` / `stateText(g)` build one plain string set via `textContent`
  (`buildPanel` ~256 and `onBatch` ~352), so it can break anywhere, including inside "112–104" and "(5–7)".

## 4. Files owned
- `public/static/css/tonight.css` (only `.lede h1 .n` and a new `.panel p.meta .nw` rule)
- `public/static/js/tonight/drawer.js` (only `metaText`/`stateText` and the two places that write `[data-meta]`)
- `public/static/css/base.css` (add a global `.nw{white-space:nowrap}` utility)

## 5. Complete solution looks like
- `.lede h1 .n{white-space:nowrap}` — every number/record/money/odds span in the lede stays on one line.
- Drawer meta: build it as DOM nodes: plain text for words, `<span class="nw">` for each team-with-record
  ("Miami Heat (5–7)" — the whole team name + record in one nowrap span is too long on phones; so make the record
  alone nowrap: "Miami Heat " + nw"(5–7)"), the time ("7:00 PM ET"), and the score block ("MIA 112–104 ORL" → nw for
  "112–104"; tricodes outside). A helper `setMeta(p, g)` that clears `p` and appends nodes (textContent only) replaces
  `p.textContent = metaText(g)` in both places. Keep `metaText()` returning the same plain string (used for nothing
  else? check) — or remove it if unused.
- Separators " · " stay as text with normal spaces, so breaks happen there.
- Text content unchanged apart from dashes (D4 will change "(5-7)" to "(5–7)" — do NOT change dashes here).
- Reduced motion n/a.

## 6. Out of scope
Hyphen → en dash (D4), "№" (D11), kicker (D2), tape bars (B4).

## 7. Acceptance tests (`tests/e2e/audit/D3.mjs`)
- Lede: for every `.n` in `[data-testid=hero]`, `getClientRects().length === 1` at every scene × width.
- Drawer: for every `.nw` in `[data-meta]`, `getClientRects().length === 1`; and no line of the meta paragraph starts
  or ends inside a `\d[–-]\d` pattern: use a Range over each score/record match and assert its client rect count is 1.
- Audit fix text — *wrap records, scores and money in nowrap spans*.
- `page.errors` empty; no horizontal overflow at 320.
