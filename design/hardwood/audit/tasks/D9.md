# D9 · Ticket toolbar: filters on one scrollable row, "Sort" + sort buttons on their own row

## 1. Problem
At 400 and 768 the toolbar wraps so "FINAL 1" and "SORT" end up orphaned on their own lines (toolbar 146px tall at
400, 100px at 768). Screenshot: `design/hardwood/audit/shots/D9-toolbar-wrap-400.png`.

## 2. Repro
`/?sample=1&scene=live` at 320, 400, 768, 1024, 1440 → `[data-toolbar]`.

## 3. Root cause
`public/static/css/tonight.css` ~53–58: `.toolbar{display:flex;flex-wrap:wrap;gap:12px 28px}`, `.tg{display:flex;flex-wrap:wrap}`.
Markup (`public/index.html` ~100–104): `.toolbar > [data-testid=filters].tg, span.tg-lbl "Sort", [data-testid=sorts].tg`.

## 4. Files owned
- `public/static/css/tonight.css` (only `.toolbar`, `.tg`, `.tg-lbl` rules)

## 5. Complete solution looks like
At `max-width: 1100px` (any width where the single row would wrap; at 1440 it fits on one 44px row — unchanged):
- `.toolbar{display:grid; grid-template-columns:auto minmax(0,1fr); column-gap:12px; row-gap:6px; align-items:center}`.
- Filters (`[data-testid=filters]`) span the full width on row 1: `grid-column:1/-1; flex-wrap:nowrap; overflow-x:auto;
  scrollbar-width:none; scroll-snap-type:x proximity`, buttons `flex:none; scroll-snap-align:start`. Five filters with
  counts on one line; if they don't fit (320px), the row scrolls inside itself — the page never scrolls horizontally.
- Row 2: "SORT" label (`.tg-lbl`, inline, vertically centred) then the three sort buttons on one line (`flex-wrap:nowrap`).
- Touch targets stay ≥ 44px tall; focus rings not clipped (scroller `padding-block:2px`).
- Keyboard order unchanged (filters, then sorts). Filter/sort behaviour unchanged (validate.mjs clicks
  `[data-testid=sorts] [data-s=edge]` and `[data-testid=filters] [data-f=bets]` — they must stay clickable/visible;
  `scrollIntoViewIfNeeded` is fine).
- Toolbar height ≤ 2 × 44 + 6 + padding ≈ 100px at ≤ 1100px.

## 6. Out of scope
toolbar.js, the section heading, ticket grid.

## 7. Acceptance tests (`tests/e2e/audit/D9.mjs`)
For w in 320, 400, 768, 1024:
- All `[data-testid=filters] button` share one top (±2px); all `[data-testid=sorts] button` and `.tg-lbl` share one top
  (±4px, label centred); the sorts row is below the filters row.
- No button is alone on a line (follows from the two above).
- `document.documentElement.scrollWidth <= innerWidth`.
- Clicking `[data-f=final]` (after `scrollIntoViewIfNeeded`) sets `aria-pressed="true"` on it.
At 1440: all filters, the label and sorts share one row (toolbar height ≤ 48).
`page.errors` empty.
