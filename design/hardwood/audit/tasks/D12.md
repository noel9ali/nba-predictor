# D12 · Model hero: no big empty band above the step kicker

## 1. Problem
The Model hero reserves the height of its tallest state for `.pin__head` (M2, so the court never jumps), but the head
is `justify-content:flex-end`, so in the first state ("Home-team rule", one short line) the spare height shows as a
large empty band between the page kicker and the "1 OF 2 · THE BAR TO BEAT" step kicker: 123px at 400, 149px at 768,
206px at 1440 (measured). Screenshot: `design/hardwood/audit/shots/model-hero-1440.png`.

## 2. Repro
`/model?sample=1` at 400, 768, 1440, top of the page (base state). Then scroll ~40% through `[data-scrolly]` (model
state) and compare.

## 3. Root cause
- `public/static/js/model/claim.js` `sizeHead()` ~43–57 measures a clone in both states (title + explanation) and sets
  `.pin__head` `min-height` to the max. Re-measures on resize and `document.fonts.ready` (keep both).
- `public/static/css/model.css` line ~10: `.pin__head{display:flex;flex-direction:column;justify-content:flex-end}`.

## 4. Files owned
- `public/static/css/model.css` (only `.pin__head` rules)
- `public/static/js/model/claim.js` (only `sizeHead`)

## 5. Complete solution looks like
- Keep reserving the head's height (court position must not move between states — M2), but put the spare space
  BELOW the text, not above it: `.pin__head{justify-content:flex-start}`. Then the step kicker sits right under the
  page kicker in both states, and the reserved space is between the explanation and the court.
- `sizeHead()`: unchanged logic, but make sure it measures with the real fonts (it already re-runs on
  `document.fonts.ready`) and on width changes only (resize handler exists). If the clone measurement includes the
  current `min-height`, ensure the clone has `min-height:0` (it does — verify).
- In the model state the head is as tall as before; the court's top is at the same y in both states (±1px).
- Reduced motion (instant swap): same layout.

## 6. Out of scope
Kicker text (A2/A3), court, legend, scroll cue.

## 7. Acceptance tests (`tests/e2e/audit/D12.mjs`)
For w in 400, 768, 1440:
- Base state: `.pin__k.top − .claim > .k.bottom` ≤ 40px (before: 123/149/206).
- Court top (`[data-court-slot]` rect top relative to `.pin` top) is equal in base and model states (±1px):
  scroll to the model state by scrolling the window so `[data-scrolly]` is ~40% through, wait 600ms, check
  `.pin[data-state="model"]`.
- `page.errors` empty.
