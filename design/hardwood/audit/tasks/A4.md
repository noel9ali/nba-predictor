# A4 · Final toasts: "Tonight $X" is the running total after that game

## 1. Problem
When several games go final in one live batch, every final toast's "Tonight ±$X" shows the end-of-batch settled total.
In replay the DEN loss toast says "Tonight +$64.07" but the total after that game was +$36.28.
Screenshot: `design/hardwood/audit/shots/B1-toast-running-total.png`.

## 2. Repro
`/?sample=1&scene=replay` at 1440 (toasts are the same at every width). Step the feed with
`await page.evaluate(() => window.__sampleFeed.step())` up to 6 times; read `[data-toasts] .toast` after each step.

## 3. Root cause
`public/static/js/tonight/toasts.js` `finalSentence()` (line ~35): `fmt.money(summary().settled, true)` runs after the
whole batch is merged into the store, so all toasts in one batch print the same end total. `onBatch(changes)` walks the
batch's change records in order.

## 4. Files owned
- `public/static/js/tonight/toasts.js`

## 5. Complete solution looks like
- In `onBatch`, before the loop: `end = summary().settled`; `inBatch` = sum of `c.pl` over this batch's `final`
  records whose game has a bet (`game(c.id) && game(c.id).bet && c.pl != null`); `running = end − inBatch`.
- Walk the records in order; for each final-with-bet record: `running += c.pl`, then build its toast with
  `Tonight ${fmt.money(running, true)}`. Pass `running` into `finalSentence(g, rec, running)`.
- Wording unchanged: head `Final: DEN 101, MIN 109.`, tail `Lost −$27.79. Tonight +$36.28.`
- Tip toasts, no-bet toasts, past mode (no toasts): unchanged.

## 6. Out of scope
Toast styling/timing/count; state.js.

## 7. Acceptance tests (`tests/e2e/audit/A4.mjs`)
At 1440, replay scene. Helper `amt(s)`: replace '−' with '-', strip `$ , + ±`, parseFloat.
For each of 6 steps:
1. `prev` = amt of `[data-testid=settled]` text before the step (scorers board).
2. Step; wait 300 ms; collect toasts that weren't there before, in DOM order, whose text contains 'Tonight'.
3. Chain check: `running = prev`; for each such toast, `running += amt(Cashed/Lost amount)` and assert the toast's
   Tonight value equals `running` within 0.01. After the last, assert `running` equals the board's new settled value.
- Explicit: some toast containing 'DEN' reads `Tonight +$36.28`.
- Audit "Accept when" — *Each toast's "Tonight" equals settled P/L after that game only* — is the chain check.
- `page.errors` empty.
