# A6 · Scorers board: no "0 of 0", and one "No bets tonight" cell when there are no bets

## 1. Problem
Final scene: the board shows "Live picks ahead 0 of 0". No-bets scene: `$0.00 / ±$0.00 / ±$0.00 / 0 of 0 / 0–0 / 0–0`.
Screenshots: `design/hardwood/audit/shots/D3-D10-final-lede-wrap.png`, `design/hardwood/audit/shots/D10-nobets-board.png`.

## 2. Repro
`/?sample=1&scene=final`, `scene=nobets`, `scene=live`, `scene=nextup`, `scene=replay`, and past mode
`/?sample=1&date=2026-11-16` at 400/768/1440. Read `[data-testid=tape] > div` (dt/dd pairs).

## 3. Root cause
- `public/static/js/tonight/glance.js` `boardCells(s)` (lines ~28–37) always returns six cells.
- `public/static/js/board.js` `renderBoard()` pads to six (`while (list.length < 6) …`) and rebuilds only when the
  child count isn't 6.

## 4. Files owned
- `public/static/js/tonight/glance.js` (only `boardCells`)
- `public/static/js/board.js`
- `public/static/css/components.css` (only the `.board` rules, lines ~43–62)

## 5. Complete solution looks like
- `renderBoard(dl, cells)` renders exactly `cells.length` cells (1–6; cap at 6), no padding. It rebuilds the children
  only when the count differs, so live batches with the same count still update in place (node identity kept).
  The loading call in `renderLede` (six '—' cells) and `seasonError` (six cells) keep working unchanged.
- `boardCells(s)`:
  - `s.bets === 0` → exactly one cell `{ label: 'Tonight', value: 'No bets tonight' }`.
  - otherwise the current six cells, minus "Live picks ahead" when `s.liveBets === 0` → five cells.
    With live bets it reads e.g. "2 of 3".
- The board CSS (`public/static/css/components.css` lines ~43–62) hard-codes 6 columns (3 at ≤960px, 2 at ≤520px), so
  5 or 1 cells would leave empty slots. Fix: `renderBoard` sets `dl.dataset.cells = String(n)`; CSS:
  - desktop: `.board[data-cells="5"]{grid-template-columns:repeat(5,minmax(0,1fr))}`, `[data-cells="4"]` → 4,
    `[data-cells="1"]` → `minmax(0,1fr)` (1 cell spans the full board width, text left-aligned as other cells).
  - ≤960px (3 columns): 5 cells → rows of 3 + 2; the 2 cells on row 2 stay in columns 1–2, no bottom border on row 2;
    1 cell → `grid-template-columns:minmax(0,1fr)` and no bottom border.
  - ≤520px (2 columns): 5 cells → 2 + 2 + 1; the last cell spans both columns (`grid-column:1/-1`) with no bottom
    border, the cells above it keep their bottom borders; 1 cell → one full-width cell, no borders inside.
  - 6 cells: exactly as today at every width.
  Keep the rule style of the file (one line per rule, same property order).
- Ribbon (`ribbon.js`) unchanged.
