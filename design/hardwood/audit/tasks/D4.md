# D4 · En dashes, never hyphens, in records, scores and seasons (designer ruling 4)

## 1. Problem
Hyphens appear where ruling 4 requires an en dash (–): drawer records "(5-7)", bankroll tooltip "bets 2-1 · picks 6-3",
past-night step copy "(bets 2-1, picks 6-3)", and anywhere an API record/season string is printed raw.

## 2. Repro
Sweep (the test below automates it): `/?sample=1&scene=<live|final|nobets|replay>`, past `/?sample=1&date=2026-11-16`,
`/model?sample=1` at 1440; open drawers; hover/arrow through the bankroll chart; switch seasons in Model chapter 1.

## 3. Root cause
`public/static/js/format.js` already has `wl()` (records) and `seasonLabel()` (seasons) — but `wl` uses
`.replace('-', NDASH)` (first hyphen only) and some call sites print raw strings:
- `public/static/js/tonight/drawer.js` `setMeta(p, g)` (D3 rebuilt the meta line as nodes): `' (' + g.away.record + ')'` and the home record are printed raw.
- `public/static/js/tonight/season.js` `tipContent(x)` (~140–144): `'bets ' + x.bets + ' · picks ' + x.picks`;
  `stepText` past-night branch (~56): `'(bets ' + night.bets + ', picks ' + night.picks + ')'`.
- Any other raw record/season/score join found by `grep -rnE "\+ ?'-' ?\+|'-'\)|\"-\"|record\b|\.bets\b|\.picks\b|season\b" public/static/js`.

## 4. Files owned
- `public/static/js/format.js` (only `wl`, `seasonLabel`, and a new `fmt.record` alias if you want one)
- `public/static/js/tonight/drawer.js` (only the record strings in `setMeta`)
- `public/static/js/tonight/season.js` (only `tipContent` and the past-night sentence in `stepText`)
- `public/static/js/model/alltime.js`, `public/static/js/model/seasons.js`, `public/static/js/model/walkthrough.js`
  (only string formatting of records/seasons, if the sweep finds hyphens there)

## 5. Complete solution looks like
- `wl(s)` and `seasonLabel(s)` replace every ASCII hyphen between digits with an en dash:
  `String(s ?? '').replace(/(\d)-(\d)/g, '$1' + NDASH + '$2')`. Null → ''.
- Every printed record (team records, bets/picks W–L), season label and score uses them:
  drawer "Miami Heat (5–7)", tooltip "Night +$12.40 · bets 2–1 · picks 6–3", past step "(bets 2–1, picks 6–3)".
- Dates (YYYY-MM-DD) are never printed raw (they go through date formatters) — don't touch date code.
- Update `tests/js/pure.test.mjs`? — you don't own it; if an existing `wl` test breaks, report it.
- The minus sign for money/odds stays U+2212 (format.js already does this).

## 6. Out of scope
