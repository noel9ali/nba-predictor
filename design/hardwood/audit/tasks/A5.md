# A5 · "Next up" never points to a game whose tip time has passed

## 1. Problem
In the feed-down scene the lede says "Next up: MIA +105 at 7:00 PM" at 9:09 PM. When live data is missing, games
past their tip time keep `state === 'scheduled'` and still count as next up.
Screenshot: `design/hardwood/audit/shots/B2-feeddown-stale-nextup.png`.

## 2. Repro
`/?sample=1&scene=feeddown` at 400/768/1440 (sample clock 2026-11-18T02:09:30Z = 9:09 PM ET); read
`[data-testid=hero]`. Also scenes live, nextup, sofar, edges, replay.

## 3. Root cause
- `public/static/js/state.js` lines 136–141: `nextUpOf(games)` keeps every scheduled game with a bet, whatever its
  `tip_time_utc`. `nextUp = () => nextUpOf(store.games)`.
- `public/static/js/tonight/glance.js` `sentence()` lines ~57–61: when `nextUp()` is null it says
  "Every bet has tipped. If it ended now: …", which is also wrong while unstarted bets remain (feed down).

## 4. Files owned

- `public/static/js/tonight/glance.js` (only `sentence()`; another task edits `boardCells` later — leave it)
- `tests/js/pure.test.mjs` (add a unit test)

## 5. Complete solution looks like
- `export function nextUpOf(games, nowMs = Date.now())`: candidates = `state === 'scheduled'` && `hasBet(g)` &&
  `tipMs(g) > nowMs` (no tip time → `tipMs` is Infinity → still qualifies). Same sort as today.
- `export const nextUp = () => nextUpOf(store.games, now());` (`now()` is the sample-aware clock already in state.js).
- Add `export const pendingBets = () => store.games.some(g => g.state === 'scheduled' && hasBet(g));`
- glance.js `sentence()`: where it does `if (!nu) return 'Every bet has tipped…'`, return `found` (the
  "The model found N bets in M games." sentence) when `pendingBets()` is true, else the existing "Every bet has
  tipped" sentence. To do that, compute `found` before the `!nu` check. Import `pendingBets` from state.js.
- Required end states:
  - feeddown: "The model found 5 bets in 8 games." (numbers from the data; no "Next up" clause).
  - nextup scene: unchanged, still "… Next up: <TRI> <odds> at <time>, edge +x.x."
  - live/sofar/edges/replay: a "Next up" clause only if its tip time is after the scene clock.
- Unit test in `tests/js/pure.test.mjs`: three scheduled bet games tipping at T−1h, T+30m, T+2h with now=T →
  `nextUpOf(games, T).game_id` is the T+30m game; now after all tips → null; a bet game with `tip_time_utc: null`
  still qualifies. Follow the existing test style in that file (node:test + assert/strict, existing fixtures).
