# Hardwood frontend audit, Oct 7 2026

**Scope:** deployed `public/` (Tonight `index.html`, Model `model.html`), audited at 1440 / 768 / 400 px with Playwright (Chromium) behind the production CSP headers, in sample mode (`?sample=1`) across every scene (`live, nextup, sofar, final, nobets, before, failed, offseason, edges, stale, feeddown, replay`), past mode (`?date=2026-11-16`), keyboard, reduced motion and a "production-like" Model page (`production_model` = gradient boosting, and a degraded variant with `/api/game` 404 to mirror `NBA_SCHEMA_V2` off).

**Clean:** no console errors, no CSP violations, no horizontal page overflow at any width, reduced motion shows end states, no broken images.

**Not covered:** a real-data pass on production (`nba-predictor-tau.vercel.app` is behind Vercel SSO and the sandbox can't reach Supabase). Repeat items A1–A3 against real data once signed in.

Screenshots are in `shots/` (file name starts with the finding ID). Raw automated checks: `automated-checks.json`.

Severity: **A** = broken or wrong data · **B** = functional / accessibility bug · **C** = chart and label collisions · **D** = layout and polish.
