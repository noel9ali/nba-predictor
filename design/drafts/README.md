# Design drafts

Snapshot of the NBA Predictor dashboard design, saved Sept 22, 2026.

The live, editable version is the Design canvas:
https://claude.ai/code/artifact/a702b1d5-c99f-4bf4-b134-aa7cb93049c2

- `Games.dc.html`: current Games page draft (Round 2, direction C). Tonight's slate with pregame, live and final states, the "next up, biggest edge" hero, and last night's results.
- `Broadcast.dc.html`: the Round 1 "sports broadcast" concept the direction came from.
- `canvas.json`: the canvas layout index.

These are Design Component sources. They render on the canvas, not as standalone web pages. The final site will be a separate self-contained HTML file.

To continue the design work, start a new session with `../DESIGN_SESSION_PROMPT.md`.
